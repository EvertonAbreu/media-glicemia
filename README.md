## 📋 Sobre o Projeto

O **DiabCare** é um sistema web completo para monitoramento de glicemia e insulina, desenvolvido para auxiliar pacientes diabéticos no controle diário de suas medições. O sistema armazena dados localmente no navegador, garantindo privacidade e facilidade de uso.

## ✨ Funcionalidades

- 📊 **Registro de medições** com data, hora e dia da semana
- 💉 **Campo inteligente de insulina** (aparece automaticamente quando necessário)
- 🎨 **Alertas visuais** para níveis alterados (alta/baixa)
- 🔍 **Filtros** por data e status da glicemia
- 📈 **Estatísticas em tempo real** (total, média, dias monitorados)
- 💾 **Armazenamento local** (não perde dados ao recarregar)
- 📥 **Exportação de dados** para backup
- 📱 **Design responsivo** (funciona em celulares, tablets e computadores)
